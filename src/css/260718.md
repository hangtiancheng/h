### CSS 选择器的优先级

specificity 特异性四元组 (a, b, c, d)

- a: 内联样式
- b: ID 选择器的数量
- c: 类, 伪类, 属性选择器的数量
- d: 元素, 伪元素选择器 (例如 ::before, ::after) 的数量

\* 通配符选择器, > 子选择器, + 相邻兄弟选择器, ~ 通用兄弟选择器不影响选择器的优先级

建议

- 避免使用 ID 选择性: 特异性高, 导致样式覆盖难
- 避免使用 !important: !important 特异性最高, 破坏层叠规则
- 使用 BEM 命名规范

### CSS 绘制三角形

1. 4 条 border: 元素的宽高为 0, 4 条 border 宽度不为 0, 4 条 border 形成 4 个三角形; 1 条 border 有 border-color, 3 条 border 设置为 transparent, 得到一个三角形
2. 3 条 border: 元素的宽高为 0, 1 条 border 有 border-color, 相邻的 2 条 border 设置为 transparent, 得到一个三角形
3. linear-gradient 线性渐变
4. clip-path 裁剪

::: code-group

```css [4 条 border]
.triangle {
  width: 0;
  height: 0;
  border-top: 40px solid green;
  border-right: 40px solid transparent;
  border-bottom: 40px solid transparent;
  border-left: 40px solid transparent;
}
```

```css [3 条 border]
.triangle2 {
  width: 0;
  height: 0;
  border-left: 40px solid transparent;
  border-right: 40px solid transparent;
  border-bottom: 70px solid green;
}
```

```css [linear-gradient 线性渐变]
.triangle3 {
  width: 80px;
  height: 80px;
  background: linear-gradient(to bottom right, green 50%, transparent 50%);
}
```

```css [clip-path 裁剪]
.triangle4 {
  width: 80px;
  height: 80px;
  background: green;
  clip-path: polygon(50% 0, 0 100%, 100% 100%);
}
```

:::

### Web Component 样式隔离

Web Component 使用 Shadow DOM 实现样式隔离, 宿主元素调用 `el.attachShadow({ mode: 'open' })`, 在宿主元素内挂载一棵影子 DOM 树, 影子 DOM 树有独立的 DOM 作用域和样式作用域

Shadow DOM 可以隔离 CSS 选择器, 不能隔离 CSS 继承

```html
<style>
  :root {
    /* 不能隔离 CSS 继承 */
    --theme-primary: lightblue;
    font-family: "Menlo", sans-serif;
  }
  .card {
    /* 可以隔离 CSS 选择器 */
    color: lightgreen;
  }
</style>

<div class="card">lightgreen text</div>
<my-card></my-card>

<script>
  class MyCard extends HTMLElement {
    constructor() {
      super();
      const shadow = this.attachShadow({ mode: "open" });
      shadow.innerHTML = `
      <style>
        .title {
          color: var(--theme-primary, #000);
        }
        .card2 {
          padding: 1rem;
          border: 1px solid #ccc;
          border-radius: 0.5rem;
        }
      </style>
      <div class="card2">
        <h3 class="title">lightblue text</h3>
        <p>Menlo font, black text</p>
      </div>
    `;
    }
  }
  customElements.define("my-card", MyCard);
</script>
```

### 介绍 CSS 原子化、css-in-js、CSS 模块化

CSS 原子化 (tailwindcss)

- 组合 CSS 原子类, 而不是自定义 CSS
- 构建时扫描源文件, 提取所有使用的类名
- 支持 JIT (Just-In-Time) 按需生成 CSS 规则
- 构建产物是静态 CSS 文件, 零 JS 运行时开销

css-in-js (styled-components)

- 渲染时 (运行时) 将模版字符串解析为 CSS 字符串
- 计算 CSS 字符串的 hash, 生成唯一 CSS 类名
- 通过 `<style>` 标签或 `CSSStyleSheet.insertRule()` 插入 html 文档
- 有缓存, 一个样式只插入一次

CSS 模块化 (.module.css)

- 构建工具 (Webpack CSS loader、Vite) 处理 .module.css 时, 对 CSS 类名加 hash 后缀
- 构建产物是静态 CSS 文件, 零 JS 运行时开销

性能: CSS 原子化 = CSS 模块化 > css-in-js

CSS 原子化和 CSS 模块化的构建产物都是静态 CSS 文件, 可以 preload, 可以并行解析 DOM 树和 CSSOM 树、可以独立缓存
而 css-in-js 是运行时生成 CSS 样式并插入 html 文档

### PostCSS

CSS 中的 Babel

- 将 CSS 字符串解析为 AST 抽象语法树
- 插件遍历、修改 AST 节点
- 将修改后的 AST 重新序列化为 CSS 字符串
- 支持生成 Source Map

场景

- CSS 语法降级
- autoprefixer 添加浏览器前缀
- CSS 压缩
- px 转 rem/..., 移动端适配
- tailwindcss
- stylelint

### React Native 的 CSS 对比 Web 的 CSS, Yoga 布局引擎

React Native 不是浏览器, 没有 DOM、没有 CSSOM; RN 中的 CSS 是使用 CSS 属性名和 flexbox 语义的 JS 对象, 使用 JS 对象描述样式, 底层的 Yoga 布局引擎计算布局

- RN 没有 css 文件、不支持 CSS 选择器、不支持 CSS 继承/层叠 (cascade)
- RN 数值没有单位, 是逻辑像素, 不支持 em、rem、vw、vh...
- RN 不支持伪类 (:hover)、不支持伪元素 (::before, ::after)
- RN 不支持浮动
- RN 只支持 flex 布局, 默认 `flexDirection: "column"`, Web 默认 `flex-direction: row`
- RN 不支持 CSS 过渡 (transition)、不支持 CSS 动画 (@keyframes)
- RN 不支持 CSS 变量、CSS 函数
- RN 不支持媒体查询 (@media)
- RN 不支持

Yoga 布局引擎

1. RN 旧架构: JS 的 style 对象通过 bridge 异步发送给 Yoga 节点树, 有序列化开销
1. RN 新架构: JS 的 style 对象通过 JSI 同步给 Yoga 节点树, 没有序列化开销
1. Yoga 构建布局树, 每个 RN 组件对应一个 Yoga 节点
1. Yoga 执行 flexbox 布局算法, 计算布局
1. Yoga 将计算结果跨「线程」提交给 iOS/Android 进行渲染

### 三栏布局: 中间宽度固定、两边宽度自适应

方案 1: flex 布局

- 容器: 开启 flex 布局
- 左右元素: `flex: 1`
- 中间元素: `flex: 0 0 500px`

```html
<style>
  .container {
    display: flex;
  }

  .left,
  .right {
    min-width: 0;
    /* 即 flex: 1 1 0%; 可以拉伸, 可以压缩, 主轴方向的初始大小为 0% */
    flex: 1;
    background: lightgreen;
  }

  .center {
    width: 500px;
    /*  不能拉伸, 不能压缩, 主轴方向的初始大小等于 500px */
    flex: 0 0 500px;
    background: lightblue;
  }
</style>

<div class="container">
  <aside class="left">left</aside>
  <main class="center">center 500px</main>
  <aside class="right">right</aside>
</div>
```

方案 2: grid 布局

- 容器: 开启 grid 布局, `grid-template-columns: 1fr 500px 1fr;`

```html
<style>
  .container {
    display: grid;
    grid-template-columns: 1fr 500px 1fr;
  }
</style>

<div class="container">
  <aside style="background: lightgreen;">left</aside>
  <main style="background: lightblue;">center 500px</main>
  <aside style="background: lightgreen;">right</aside>
</div>
```

方案 3: 浮动

- 左、中、右全部左浮动或右浮动
- 中间元素宽度固定 500px, 左右元素宽度使用 `calc((100% - 500px) / 2)` 计算
- 父元素使用 `::after` 创建空的伪元素以清除浮动

```html
<style>
  /* 父元素使用 `::after` 创建空的伪元素以清除浮动 */
  .container::after {
    content: "";
    display: block;
    clear: both;
  }

  .center {
    float: left;
    width: 500px;
    background: lightblue;
  }

  .left {
    float: left;
    width: calc((100% - 500px) / 2);
    background: lightgreen;
  }

  .right {
    float: left;
    width: calc((100% - 500px) / 2);
    background: lightgreen;
  }
</style>

<div class="container">
  <aside class="left">left</aside>
  <main class="center">center 500px</main>
  <aside class="right">right</aside>
</div>
```

### 三栏布局: 两边宽度固定、中间宽度自适应

方案 1: flex 布局

- 容器: 开启 flex 布局
- 左右元素: `flex: 0 0 200px`
- 中间元素: `flex: 1`

```html
<style>
  .container {
    display: flex;
  }

  .center {
    /* 即 flex: 1 1 0%; 可以拉伸, 可以压缩, 主轴方向的初始大小为 0% */
    flex: 1;
    background: lightblue;
  }

  .left,
  .right {
    /*  不能拉伸, 不能压缩, 主轴方向的初始大小等于 200px */
    flex: 0 0 200px;
    background: lightgreen;
  }
</style>

<div class="container">
  <aside class="left">left 200px</aside>
  <main class="center">center</main>
  <aside class="right">right 200px</aside>
</div>
```

方案 2: grid 布局

- 容器: 开启 grid 布局, `grid-template-columns: 200px 1fr 200px;`

```html
<style>
  .container {
    display: grid;
    grid-template-columns: 200px 1fr 200px;
  }
</style>

<div class="container">
  <aside style="background: lightgreen;">left 200px</aside>
  <main style="background: lightblue;">center</main>
  <aside style="background: lightgreen;">right 200px</aside>
</div>
```

方案 3: 浮动

- 中间元素的左右外边距固定 200px;
- 左元素左浮动, 宽度 200px;
- 右元素右浮动, 宽度 200px;
- 中间元素放在左右元素前面, 保证中间元素优先加载

```html
<style>
  .center {
    margin: 0 200px;
    background: lightblue;
  }

  .left {
    float: left;
    width: 200px;
    background: lightgreen;
  }

  .right {
    float: right;
    width: 200px;
    background: lightgreen;
  }
</style>

<div>
  <main class="center">center</main>
  <aside class="left">left 200px</aside>
  <aside class="right">right 200px</aside>
</div>
```
