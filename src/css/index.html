CSS Techniques

Drawing Triangles with Pure CSS

Six practical approaches — borders, gradients, clip-path, rotated squares, layered outlines, and a real-world speech-bubble pattern.

0Core Principle: Border Junctions Are 45° Diagonals

When an element has zero width and height, each of its four borders renders as a trapezoid, meeting its neighbors along a 45° diagonal. Set three borders to transparent and the remaining one becomes a triangle.

All four borders colored
Three borders faded 
/* Zero dimensions + four thick borders */
.box {
  width: 0;
  height: 0;
  border-top: 40px solid #ef4444;
  border-right: 40px solid #3b82f6;
  border-bottom: 40px solid #22c55e;
  border-left: 40px solid #f59e0b;
}

1The Border Technique (Classic, Best Compatibility)

Keep one border colored and its two neighbors transparent. Vary the border widths to control the triangle's proportions, or keep two adjacent borders to form a right triangle.

/* Upward-pointing triangle */
.triangle-up {
  width: 0;
  height: 0;
  border-left: 40px solid transparent;
  border-right: 40px solid transparent;
  border-bottom: 70px solid #6366f1;

/* Right triangle: two adjacent borders, one colored */
.triangle-right-angle {
  width: 0;
  height: 0;
  border-top: 60px solid #6366f1;
  border-right: 60px solid transparent;
}

2The Gradient Technique

A hard color stop at 50% inside a linear-gradient draws a clean diagonal edge — ideal for corner cuts and arrow icons. Two gradients, each painting half the box, combine into a directional arrow.

Corner cut
Up arrow 
/* Corner cut: hard stop at 50% */
.t-corner {
  width: 80px;
  height: 80px;
  background: linear-gradient(to bottom right, #22c55e 50%, transparent 50%);
}

/* Arrow: two gradients, each painting one half */
.t-arrow {
  width: 48px;
  height: 48px;
  background:
    linear-gradient(45deg, transparent 50%, #22c55e 50%),
    linear-gradient(-45deg, #22c55e 50%, transparent 50%);
  background-size: 50% 100%;
  background-position: left top, right top;
  background-repeat: no-repeat;
}

3The clip-path Technique (Most Intuitive)

polygon() clips an element to arbitrary vertex coordinates, free from the border-box model — any polygon works, and the background can be a gradient or image. Note that box-shadow outside the clipped region is cut away too.

Isosceles triangle
Arbitrary triangle 
/* Isosceles triangle */
.t-clip {
  width: 100px;
  height: 90px;
  background: linear-gradient(180deg, #f59e0b, #ef4444);
  clip-path: polygon(50% 0, 0 100%, 100% 100%);
}

4The Rotated-Square Technique (Easiest to Outline)

Give a square two adjacent borders and rotate it 45°. Because its background and border colors can match the container, this is the standard way to build popover and tooltip arrows.

Small outlined arrow pointing up 
.t-rotate {
  width: 48px;
  height: 48px;
  background: #fff;
  border-left: 2px solid #ef4444;
  border-top: 2px solid #ef4444;
  transform: rotate(45deg);
}

5Outlined Triangle: The Layered Technique

The border technique cannot outline a triangle on its own. The workaround: paint a slightly smaller pseudo-element triangle in the fill color and offset it by 1–2px over a larger triangle in the outline color — the exposed rim becomes the stroke.

White triangle with a purple stroke 
.t-bordered {
  position: relative;
  width: 0;
  height: 0;
  border-left: 30px solid transparent;
  border-right: 30px solid transparent;
  border-bottom: 50px solid #8b5cf6; /* Outer layer: outline color */
}
.t-bordered::after {
  content: '';
  position: absolute;
  left: -28px;
  top: 3px;                       /* Offset down to reveal the top edge */
  border-left: 28px solid transparent;
  border-right: 28px solid transparent;
  border-bottom: 47px solid #fff; /* Inner layer: fill color, slightly smaller */
}

6Putting It Together: The Speech Bubble

In production UI, triangles usually appear as pointer arrows on bubbles, dropdowns, and menus. The rotated-square approach (Section 4) lets the arrow share the bubble's background and border for a seamless look.

Arrow on top — typical of dropdown menus and popovers
Arrow on the bottom — typical of tooltips and guided tours 
.bubble {
  position: relative;
  background: #fff;
  border: 1px solid #e2e5ea;
  border-radius: 8px;
}
.bubble-arrow {
  position: absolute;
  top: -7px;
  left: 24px;
  width: 12px;
  height: 12px;
  background: #fff;               /* Matches the bubble background */
  border-left: 1px solid #e2e5ea; /* Matches the bubble border */
  border-top: 1px solid #e2e5ea;
  transform: rotate(45deg);       /* Use rotate(225deg) for a bottom arrow */
}

★Comparison at a Glance

Choose the technique that fits your constraints: compatibility, outline support, and background flexibility.

Technique Strengths Trade-offs Best for
Border Widest browser support; zero dependencies No outlines; solid colors only Simple solid triangles
Gradient Compact; no extra elements Limited to diagonal cuts Small icons and corner cuts
clip-path Any polygon; gradients and images allowed Clips away box-shadow outside the shape Complex shapes and hero graphics
Rotated square Supports real borders that match the container Only right-angle arrows at 45° Popover and tooltip arrows
Layered outline Adds a stroke to the border technique Fragile pixel offsets; fill color must be solid Outlined triangles without SVG
