## Data

- rrweb 的 record() 启动后, 每产生一个事件 (DOM 增量、点击、滚动), 都会通过 emit 回调 push 到一个数组; rrweb 记录的是结构化的 DOM 增量事件不是视频, 开销小,「全程录制」是可行的
- 只保留最近 3s: 每次 emit 时丢弃更早的事件
- 上报事件命中触发类型 (Error/Xhr/Fetch/Resource/UnhandledRejection) 时, 设置 shouldScreenRecord = true, ScreenRecordPlugin 将事件 JSON gzip 压缩, 附加到错误数据

rrweb 的 checkoutEveryNms 按窗口长度 3s 定期生成新的全量 DOM 快照, 回放必须从一个全量 DOM 快照开始重建 DOM

rrweb 是 dynamic import 异步加载的, 缓解手段是 requestIdleCallback

### JSError 携带的信息

- message: ErrorEvent.message / Error.message
- name: ErrorEvent.filename / Error.name
- line / column: ErrorEvent.lineno / colno
- stack: Error.stack

代码错误 (window.addEventListener("event", fn)) 可以直接拿到 filename/lineno/colno, 运行时抛出的 Error 对象没有 lineno/colno, 但是 stack 调用栈包含调用帧信息, 两种都要覆盖

- window.addEventListener("event", fn): 浏览器派发 ErrorEvent, ErrorEvent 对象携带 filename/lineno/colno
- 运行时的 Error 对象 (try-catch 捕获, Promise 拒绝的 reason 等) ECMAScript 规范只有 name 和 message, 没有 lineno/colno; 但是 stack 字符串
