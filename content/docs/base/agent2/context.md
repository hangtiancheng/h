# 会话上下文

1. 滑动窗口, 取最近 N 轮消息
2. RAG 召回最相关的 topK 轮候选消息
3. 保留关键事实, 例如有些消息, 整个会话都必须携带, 例如: 我想了解一下 iPhone17..., 先判断某条消息是否为关键事实, 如果是则标记为关键事实

## 早期消息, 截断 or 压缩?

1. 最近的几轮消息原样保留
2. 中间层的消息
   - 原样保留用户消息
   - Agent 客服消息保留一定长度的前缀
   - 小的工具调用结果可以保留, 大的工具调用结果可以替换为占位符
3. 最远的、未被压缩的几轮消息「异步」压缩成摘要; 并标记为「历史摘要」; 后续上下文压缩不会重复压缩已被压缩过的摘要

上下文窗口大小 (不是消息的轮数) 超过预算时, 后台异步开启摘要任务, 任务完成后存储到摘要表; 等到下一轮, 将消息历史中最远的、未被压缩的几轮消息替换为摘要, 不会阻塞用户

```js
const messages = [
  { role: "system", content: "你是电商 Agent..." },
  // 中间层的消息
  // 原样保留用户消息
  // Agent 客服消息保留一定长度的前缀
  { role: "user", content: "" },
  { role: "assistant", content: "" },
  // 最近的几轮消息: 原样保留
  { role: "user", content: "" },
  { role: "assistant", content: "" },
  // 用户当前的消息
  { role: "user", content: "" },
  // 本轮会话的材料
  { role: "user", content: "[历史摘要] " },
];
```
